# 图标修复 0.7.5

[English](icon-validation.en.md)

## 问题是什么

ICO 嵌入程序后，原生窗口仍可能使用通用图标。

## 为什么

资源声明不等于窗口图标设置。IDI_ICON1 是字符串资源名。Qt 界面需要显式应用图标资源。

## 改了什么

修复可执行文件图标，补齐打包中的 ICO 和资源脚本。 为窗口显式设置大小图标，随 DPI 更新并释放图标句柄。

## 实测

2026-11-09：从提交副本以 MSVC 19.51 / x64 Release 构建；CTest 4/4 通过。资源和真实插件进程检查 92/92 通过（docs/icon-checks.json），含命名资源、8 个尺寸、协议初始化和正常退出。 实际窗口的大小图标像素与 app.ico 一致，96/120/144/192 DPI 和 60 次重复切换通过，GDI/USER 句柄数量保持稳定。真实 WinShun 独立配置中通过查询与 Enter 打开窗口，图标检查通过，宿主正常退出。 另修复关闭编辑器时持有上下文互斥锁等待线程退出的死锁；新增双窗口退出回归。

## 没测的

未自动操作真实任务栏与 Alt+Tab 切换；没有重新验证所有插件功能、硬件路径、跨显示器实际拖动、UAC 安全桌面或全部 Windows 版本。本轮只制作本地标签和安装包，未公开发布。 可选 Qt 编辑器原型未构建，本包是原生 GDI 编辑器。
