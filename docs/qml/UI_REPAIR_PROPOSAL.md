## 2. 对应修复设计

### H01：hosts 列表只显示映射

- 仅在展示投影中过滤 `isSection`，保留底层原始行、原始字节、行号和稳定 ID。
- 独立注释、空行、未知或格式错误行在全文中保留；列表搜索、选中数、全选、复制和批量命令都只作用于可见映射。
- `# 127.0.0.1 api.test` 是停用映射，仍显示；`# 本地开发环境` 是注释，隐藏。不能用“以 # 开头”一刀切。
- `127.0.0.1 api.test # 行尾注释` 保留行尾注释列和编辑入口。
- 全文变化后重新建立投影；用稳定 ID 修剪过期选择，不用列表下标当文件行号。
- 空列表文案区分“没有映射”和“没有匹配”；可切到全文查看剩余内容。

### H02：状态与选择分开呈现

| 状态 | 行背景 | 状态单元格 | 其他提示 |
|---|---|---|---|
| 启用 | panel 普通底色 | 绿色 `● 启用` | 映射文本正常 |
| 停用 | 中性浅色 / 深色 field | 琥珀色 `Ⅱ 停用` | 不降低整行 opacity，保留文字对比度 |
| 新增 | greenbg 整行浅绿 / 暗绿，选中时仍保留 | `+ 新增` | 绿色文字与侧标，保存后回归正常状态 |
| 待删除 | redbg 整行浅红 / 暗红 | `− 待删除` | 左侧红色标记，映射文本删除线，允许恢复 |
| 已修改但未删除 | 保留启停对应底色 | 另一个“修改状态”列写 `● 已修改` | 不把“已停用”和“已修改”混为一个状态 |
| 选中 | 正常行加 soft；待删除行仍用 redbg | 状态标签保留 | 复选框 + accent 描边，焦点独立显示 |

绘制优先级：删除背景 > 新增绿色背景 > 选中填充 > 停用背景 > hover > 普通背景；选择边框和焦点环单独叠加。
桥接层提供 `enabled / deleted / changeState / writable` 等独立字段，QML 不解析 `c2` 的翻译文字。
批量启停跳过待删除和不可写行，明确反馈处理 / 跳过数量；一个批量命令仍只进一次 undo。
列表 Space 规则确定为：有任一可操作停用行则整批启用，否则整批停用；复选框自身 Space 只切选择，文本输入不拦截。

### E01：用户 / 系统范围按钮

- 顶部只提供“用户变量 / 系统变量”，初始打开用户；由启动器明确定位系统变量时直接进入系统页。
- 删除“所有范围”选项和冗余的范围列。用户与系统同名变量仍是不同稳定 ID。
- 每范围保留筛选、选择集合、当前行、anchor 和滚动位置；切换先结束当前合法输入，非法输入或 IME 未结束时保留焦点并阻止切换。
- Ctrl+A、Delete、复制、批量修改仅作用于当前范围当前可见行；另一范围保存的选择不参与当前命令。
- 新增到当前范围，`addRow()` 不再重设 all；恢复草稿和启动器定位也设置正确范围。
- 两范围共用工作副本、保存事务和撤销历史。范围按钮显示各自未保存数量，保存按钮明确为“保存全部修改”，复核按用户 / 系统分组，包含当前隐藏范围。
- 系统只读时仍可查看和复制，显式说明只读；禁止编辑和批量改写。`showSystem=false` 时隐藏系统入口，并拒绝绕过 UI 的系统范围切换。

### E02：可调整列宽及按列双击

env 默认顺序：选择框 / 变量名 / 值 / 类型 / 修改状态。

| 位置 | 单击 | 双击 / 键盘等价操作 |
|---|---|---|
| 单元格 | 选择行；Ctrl / Shift 多选，已选多行中普通点按更新当前行但保留集合 | 双击按列定位编辑，只有当前命中行进入编辑；已有多选不丢失 |
| 变量名 | 同上 | 聚焦名称输入并全选；F2 同等 |
| 值 | 同上 | 切到原始值，聚焦并选中原值；不会误改名称；拆分模式由详情按钮进入 |
| 类型 | 同上 | 聚焦并展开类型选择；显式选新类型才暂存；有损转换仍按原规范复核 |
| 修改状态 | 同上 | 只查看该行变化说明，不触发编辑、启停或保存 |
| 表头文字 | 按列稳定排序，保留稳定 ID 选择 | 无额外编辑动作；第二次 click 不再反转一次 |
| 表头列边界 | 拖动调整宽度，最小值限制 | 双击适应当前筛选结果的内容；边界焦点下 Enter 等价，左右键 ±4，Shift ±20 DIP |

列宽初值：32 / 182 / 320 / 150 / 94 DIP；名称至少 100，值至少 160，类型至少 130，状态至少 88。
值列吸收多余空间；用户拖动后按用户宽度展示，不够宽时使用统一水平滚动，表头和行同步。
表头边界命中宽度 8 DIP，避免误触正文；复选框区域不触发行双击。
列宽按 env / hosts 各自保存，两种 env 范围共享列布局；排序、改变列宽不计入数据 dirty 和 undo。
自适应宽度使用当前字体的文本测量，含 padding、状态标签和边界宽度，设最大宽度；长值不造成无限撑宽。

本轮 HTML 用文本字符估算自适应宽度，只验证交互分流；Qt 实现必须使用字体测量。
HTML 类型双击定位到原生 select，弹出行为由浏览器控制；Qt 需实测 `popup.open()` 及 Esc 返回，不以 HTML 焦点检查替代。

### D01：统一紧凑桌面尺寸与列表底板

| token / 控件 | 当前 | 修复默认（逻辑 DIP） |
|---|---:|---:|
| 页边距 | 24 | 12 |
| 主列表行高 | 40 | 28 |
| 拆分项行高 / 行间距 | 46 / 5 | 28 / 0 |
| 按钮高度 | `max(32, textHeight+16)` | 26 起，按字体高度 + 上下各 4 自适应 |
| 单行输入 / 下拉框 | 36 / 样式默认约 40 | 28 起，按字体高度 + 上下各 4 自适应 |
| 复选框可见标记 | Basic 默认 28 | 14，整选择单元格 32×28 可点击 |
| 正文字号 / 标题 | 14 / 24 | 13 / 18；不靠极小字体提高密度 |
| 主间距 / 控件圆角 | 8–10 / 6 | 6 / 3 |

拆分项增加与主列表相同的 panel 底板、1 DIP 外边框、表头和连续行，空白区域也保持底板色。
删除、选择、hover 与主列表共用状态规则。上下分区保留拖动分隔条，拆分项空间不再被大输入控件挤占。
多行原文编辑器不强制压成 28 高；仅工具栏和单行控件紧凑化。输入文字、IME 候选、焦点环不得被裁切。

所有尺寸均为逻辑单位，保留系统 DPI 缩放。100% / 125% / 150% / 200% 下实测；字体增大时按字体高度增长。
普通桌面默认紧凑；HTML 的设计控制可比较 32 行高的舒适方案。触屏使用更大有效命中区，不将触屏尺寸作为桌面默认值。

优先保留当前增量 `EditorRows` / 稳定 ID / Selection / WriteService，使用共享列定义和表头扩展现有 ListView。
本轮不为调整列宽同时替换全部数据模型或写入链路。

| 顺序 | 产品改动点（已实施） | 必须通过后再继续 |
|---|---|---|
| Q1 | `EditorSession::visible()` 投影过滤；`EditorBridge::rebuild()` 补结构化状态字段 | 注释原字节保留，停用映射仍显示，Ctrl+A 不含注释；索引与原始行映射正确 |

| Q4 | 共享 `ListSurface` / 行状态组件，主列表与 PartsEditor 同步 | 明暗下四组状态及选中叠加都可识别；删除后仍可恢复 |
| Q5 | 新增 `ColumnHeader` / 列宽状态；RowDelegate 分列命中；`editRequested(rowId, field)` 逐层透传 | 拖动、排序、按列双击、连续键盘和多选互不吞事件；内容与表头对齐 |
| Q6 | 将本方案回填 F / T / C、tokens 与生成 SVG，补 Qt 键鼠和截图证据 | 不把旧截图、HTML 或 jsdom 结果当成新 QML 验收；通过后再生成新包 |

字段编辑仍走 begin / update / finish / cancel，合法值自动暂存、非法值阻止切换、一次命令一次 undo。
单元格更细的点击处理必须尊重 `finish()` 返回值，失败时不更新选择、范围、排序或焦点。
范围切换和列宽存储属于视图状态；不把它们写进目标注册表或 hosts，也不制造数据 undo 步骤。

## 新增项补充（insertion-1）

用户明确修订：新增项显示绿色，在选中位置后插入。变量、hosts、拆分项统一遵循：

- 单选后插在该项后，多选后插在当前可见顺序中最后一个选中项后；无选择（即使仍有焦点行）才追加末尾。
- 新条目自动选中、滚动到可见区域、进入编辑；绿色背景、文字和 `+ 新增` 状态不会被选中填充覆盖，蓝色选择边框保留。
- 手动插入时保留其他行的当前排列并退出列排序；清除可能隐藏新行的筛选。以后点击表头可重新排序。
- hosts 的全文、保存、撤销 / 重做、草稿恢复保持插入位置；保留原始注释、空行、BOM 与未改动行换行。
- 新增未保存项删除即移除；保存成功重建基线后清除绿色新增状态。
