# ra9fael.envhosts — 环境变量与 hosts 编辑器（Win顺 插件）

> **简体中文（默认）** · [English](README.en.md)
>
> Win顺 默认使用中文界面，也自带英文模式。因此中文说明放在 `README.md`，
> 英文说明放在 `README.en.md`，两份内容保持一致，可互相跳转。

直接在 Win顺 启动器里浏览、筛选、编辑**用户环境变量**和 **hosts 文件条目**。
每次写入前都会先备份；只有管理员才能改的目标会如实报错，而不是假装成功。

## 设计目的

- `env` —— 列出用户环境变量（可选含系统变量），按名称或值筛选，行内编辑，
  复制原始 / 展开后的值，二次确认删除，从备份恢复历史快照。
- `hosts` —— 列出 hosts 条目，筛选，切换注释，复制行，删除行（双击 Enter 确认），
  新增条目，恢复备份。
- **交互式编辑窗口** —— `env` 和 `hosts` 的第一条结果永远是
  "进入交互式编辑界面"（Enter 打开独立的 GDI 窗口）：全键盘操作、撤销 / 重做、
  冲突检测、草稿自动保存到 `WS_DATA_DIR/drafts/`。

## 安装

1. 从 [最新 Release](https://github.com/ra9fael/winshun-envhosts/releases/latest)
   下载 `ra9fael.envhosts-<version>.wsplugin`。可选：用旁边的 `.sha256` 文件核对
   SHA-256（`Get-FileHash <file> -Algorithm SHA256`）。
2. 在 Win顺 里打开 **设置 → 插件 → 已安装 → 添加插件 → 压缩包（.zip / .wsplugin）**，
   选中该文件。
3. 从本地安装包安装的插件**不会自动启用**。请在列表里打开开关；启用这一步就是你
   在确认它申请的权限（见 [权限说明](#权限说明)）。

**更新：** 用同样方式安装新版的 `.wsplugin`。Win顺 认出是同一个 id，会先询问是否
替换旧版本，并保留插件的数据目录。

**卸载：** 在 **设置 → 插件 → 已安装** 里移除。

本插件是原生 exe，以「未审核原生插件」身份收录在 Win顺 应用内的**插件库**
（条目由 [WinShun-plugins](https://github.com/LingCore/WinShun-plugins) 维护，
需维护者合并 PR），也可以从本仓库的 Release 下载 `.wsplugin` 手动安装。
要求 Win顺 ≥ 0.22.0：宿主从该版本起才会显示原生包的安装风险确认。**首次安装
和每次更新都要单独确认**，这类包不会进入「全部更新」。「未审核」表示没有经过
代码安全审核，不代表已认证。已发布的包不要替换内容，改动请发新版本。

## 从源码构建

环境要求：Windows 10/11 x64、CMake 3.21+，以及 Visual Studio 2022 及以上（MSVC）
或 MinGW-w64 GCC 13+。打包和集成测试需要 Python 3.10+。

```powershell
cmake -S . -B build -A x64                 # MSVC；MinGW 用 -G "MinGW Makefiles"
cmake --build build --config Release       # 在 plugin.json 旁边生成 envhosts.exe
ctest --test-dir build -C Release --output-on-failure
python tools/package.py                    # dist/ra9fael.envhosts-<version>.wsplugin
```

本地构建如何直接在 Win顺 里运行，以及测试和发版流程，见
[CONTRIBUTING.md](CONTRIBUTING.md)。

## 关键词与示例

| 输入 | 效果 |
|---|---|
| `env` / `hosts`（在**首行**按 Enter） | 打开交互式编辑窗口（永远是第一条结果） |
| `env` | 列出全部用户环境变量（启用后含系统变量） |
| `env path` | 筛选名称或值包含 `path` 的变量 |
| `env:set NAME=value` | `NAME` 的行内编辑行；Ctrl+Enter 保存 |
| `env:del` | 列出最近的环境变量备份以供恢复 |
| `hosts` | 列出 hosts 条目 |
| `hosts docker` | 筛选匹配 `docker` 的条目 |
| `hosts:add 127.0.0.1 my.dev` | 带确认的新增行 |
| `hosts:del` | 列出最近的 hosts 备份以供恢复 |

动作以键盘优先、按 key 排序：**Enter**（编辑 / 切换 / 确认）、
**Ctrl+Enter**（保存 / 复制）、**Shift+Enter**（复制展开值 / 用默认编辑器打开 hosts 文件）。

## 运行时依赖

- Windows 10/11、x64（编译期拒绝 32 位：否则 Wow64 文件系统重定向会让它改到
  `SysWOW64\drivers\etc\hosts`）。
- 以静态链接的 `envhosts.exe` 发布；不需要运行库。
- 常驻插件（`mode: resident`）、懒启动、`idleExitSec: 0` —— 一直驻留到 Win顺 退出，
  保证打开的编辑窗口不会被空闲回收杀掉。

## 权限说明

- `files:read` / `files:write`，作用于
  `%SystemRoot%\System32\drivers\etc\hosts`（对象形式）：读取 hosts 以列出条目，
  在切换 / 新增 / 删除 / 恢复时写入。
- `ui` —— 打开插件自己的编辑窗口所必需。
- `clipboard:write` —— 编辑窗口把值 / 行复制到剪贴板（Ctrl+C）。启动器列表里
  仍然是通过宿主复制，不走这个权限。
- **注册表访问在 Win顺 权限系统里没有对应名称。** 用户环境变量位于
  `HKCU\Environment`；读写直接调用 `RegSetValueExW`（绝不用 `setx`，它会在
  1024 字符处静默截断）。这里如实声明，而不是藏起来。
- 不申请 `processes`。申请 `elevated`（本包要求 Win顺 ≥ 0.22.0）：当 Win顺 自身以管理员
  运行、且你在设置 → 插件的 envhosts 卡片上点过一次「确认」后，插件会以管理员权限
  启动，此时系统环境变量与 hosts 均可写。Win顺 从不为插件弹 UAC；插件文件被改动后
  需要重新确认；提权后的插件不响应 AI / 命令行调用。编辑窗口状态栏右端的 ⓘ 随时
  说明当前权限与获取管理员权限的两步操作。

## 可编辑范围

| 目标 | 读 | 写 |
|---|---|---|
| 用户环境变量（`HKCU\Environment`） | 是 | 是 |
| 系统环境变量（`HKLM\...\Session Manager\Environment`） | 可选 | 提权后可写；否则删除 / 编辑给出明确拒绝信息 |
| hosts 文件 | 是 | 仅当文件可写（先探测，绝不盲写）；提权后必然可写 |

环境变量写入会保留原有的值类型（`REG_SZ` / `REG_EXPAND_SZ` / `REG_MULTI_SZ`），
并广播 `WM_SETTINGCHANGE`，让新进程能读到改动。已经在运行的进程（包括 Win顺 自己）
**不会**立即看到变化，必须重启——这是 Windows 的限制，不是插件 bug。

## 数据位置

所有数据都留在本地 `WS_DATA_DIR` 下：

- `backups/env/<timestamp>.json` —— 每次环境变量写入 / 删除前的用户范围快照
  （保留数量由 `backupCount` 控制，默认 10）。
- `backups/hosts/<timestamp>.hosts` —— 每次 hosts 写入前的逐字节原文（保留数量同样
  由 `backupCount` 控制）。
- `drafts/env.json` / `drafts/hosts.json` —— 交互式编辑窗口里未保存的编辑，
  每 30 s 及关闭 / 退出时自动写入。重新打开编辑器时会弹框询问「恢复 / 丢弃」，
  恢复后作为未保存的修改显示（仍需 Ctrl+S 才写回），丢弃则删除草稿文件。只有编辑器
  写草稿，这里不发生任何注册表 / hosts 写入。
- 不上传任何内容；无遥测；密钥和设置从不写日志。

## 失败处理

- hosts 只读（普通用户面对 `System32\drivers\etc\hosts`）：该行显示 🔒 标记，
  动作返回明确的 `E_DENIED` 错误行，并提供 Shift+Enter 的逃生口——用外部编辑器
  打开文件。不静默降级，也不假装成功。
- hosts 被记事本存成 UTF-16：返回 `E_HOSTS_UTF16`，而不是破坏编码。
- hosts 被其他进程占用：`E_HOSTS_BUSY`。
- hosts 写入采用**原地写入**（打开 + 截断 + 写入），以保留文件 ACL。这不是原子操作；
  写入中途崩溃可能留下不完整文件，恢复路径是
  `WS_DATA_DIR/backups/hosts/` 里的写前备份。
- 注册表写入失败会弹出"删除失败 / 保存失败"通知，操作记录到 stderr；
  写前备份可通过 `env:del` / `hosts:del` 恢复。
- `hostsPath` 设置支持 `%VAR%` 展开；文件不存在时给出明确的空状态。

### 交互式编辑窗口

- 窗口已在真实桌面上打开并逐项核对过渲染（分栏表格、表头、详情编辑框、
  状态栏、过滤与 Tab 切换均正常）。`CreateWindowExW` 失败时（例如无桌面会话或
  前台切换被拒），动作返回 `notify` + `keep`，你仍留在启动器里，不会崩溃。
- 窗口打开后，Windows 可能把它放到后台：启动器只承诺在
  menu / picture / showSettings / hotkey 时切到前台，不保证 `action` 也切；
  被挡住时用 Alt+Tab 找回来。
- 在按下 **Ctrl+S** 之前，编辑器不写任何东西：它会重新读取目标、比较内容指纹，
  若窗口打开期间底层 env / hosts 被改过，则中止并给出冲突提示。写前备份是恢复路径。
  未保存的编辑每 30 s 及关闭时刷入 `drafts/env.json` / `drafts/hosts.json`。
- 窗口运行在自己的 GUI 线程上；启动器对同一目标的写入会 `PostMessage` 通知重载
  （让打开的窗口反映外部改动）。两者由 `native::g_writeLock` 串行化。

#### 窗口内操作

- **列表滚动**：鼠标滚轮、右侧滚动条、`↑ ↓`、`PgUp / PgDn`、`Home / End`；
  状态栏显示「第 a–b / 共 N 行」，Tab 上带行数。窗口可拖动调整大小，列宽按比例自适应。
- **单项增删改**：`Ins` 新增一行（自动滚动到新行并清空冲突的过滤词）、
  `Del` 标记删除（再按一次恢复，未提交的新行则直接移除；被标记的行在详情区显示红色
  提示，恢复前不可编辑）、`Enter / F2` 进入详情编辑、
  `Esc` 从输入框回到表格、`Ctrl+Z / Ctrl+Y` 撤销 / 重做。详情面板右侧另有
  「+ 新增 / - 删除 / 撤销 / 重做」四个按钮，与键盘共用同一套命令。
- **多选与批量（0.5.0）**：`Ctrl+单击` 加减单行、`Shift+单击` / `Shift+↑↓`
  选连续区间、`Ctrl+A` 选中当前视图全部行、`Ctrl+C` 把所选行复制到剪贴板
  （env 为 `NAME=value`，hosts 为原行文本），`Esc` 先清除多选再关窗。
  所选行一起执行 `Del` 删除 / 恢复、hosts `Space` / `Enter` 启用 / 禁用；
  只读行、hosts 分组标题、原文页与备份页自动跳过并在状态栏报告数量。整批操作
  **只占一次撤销**，一次 `Ctrl+Z` 全部还原。状态栏显示「已选 N 行」。
- **界面语言（0.5.0）**：新增 `uiLanguage` 设置（`auto` / `zh-CN` / `en-US`）。
  跟随 Win顺 或固定中文 / 英文；宿主的 `appearance` 通知会让**已打开的窗口立即
  切换**（标题、页签、表头、快捷键条、状态栏、对话框、原生控件文字全部重绘），
  不会重建数据模型、不丢未保存的编辑。固定语言优先于宿主，`auto` 再跟随宿主。
  宿主只提供 `zh` / `en`，因此本插件只做这两种语言。
- **超长值与删除语义（0.6.0）**：env 值按 Windows 的 32767 个 UTF-16 字符判断，
  详情输入框不再因 Win32 EDIT 默认上限静默截断。硬错误（空名 / 非法名 / 控制字符）
  仍然阻止保存；超过进程环境块上限的值改为**允许保存但明确警告**——详情区常驻
  `合计 X / 32,767 字符` 计数（>90% 琥珀、超限变红）、整行变红、独立红色横幅写明
  变量名与超出量，保存确认框点名风险，成功状态栏保留警告。协议层 `env:set`
  仍硬拒绝超长值（那条路径没有界面展示警告）。在「分隔项编辑」里按 `Del` 只删
  当前分隔项，**不会**删掉整个变量；删除整个变量请用详情区/快捷键条的「删除整行」，
  它会按变量名二次确认，保存对话框还会列出所有将被删除的变量。整行标记删除后
  分隔项列表立即清空并禁用，不会再出现「删掉的项还在列表里」。
- **未保存标红（0.6.0）**：每行按打开时的快照比对——新增行绿色条 `+`、值被修改
  行琥珀色条 `●`、删除行红色条 `−`；分隔项列表里被改的项同样有琥珀点，两条
  编辑路径的改动都一眼可见。
- **实时外部变化监测（0.6.0）**：2 秒轮询（失焦降到 10 秒；模态框 / 编辑中 /
  diff 面板打开时暂停），用与保存冲突检查同一套指纹逻辑。窗口干净时直接静默
  重载；有未保存编辑时顶部出现琥珀条「目标已被外部修改：N 项差异 · 查看差异」，
  **不自动合并、不动你的改动**。
- **只读差异面板（0.6.0）**：保存撞上外部冲突时不再弹「中止 / 重试 / 忽略」，
  改为打开三快照差异面板，逐项标「我改 / 外部改 / 冲突 / 一致」并列出
  `原 / 我 / 外` 三个值；底部只有三个整体动作——重新载入（丢弃我的改动）、
  强制覆盖（保存我的）、暂不处理。琥珀条「查看差异」也能打开它。
- **备份页（0.6.0）**：「备份」页签改为双栏——左侧备份列表（带数量），右侧可
  搜索的逐变量预览，带差异标记（`= 相同 / ~ 值不同 / + 仅备份有 / - 当前多出`）。
  操作：刷新预览 / 恢复（先自动备份当前状态，恢复内容作为未保存改动载入）/ 删除
  （确认）/ 导出 JSON。
- **上下分栏（仅 env 窗口）**：表格与详情面板之间有可拖动的分隔条，两栏高度按
  最小值（列表 112px / 详情 200px）互相挤占；窗口最小尺寸由 `WM_GETMINMAXINFO`
  保证两栏都放得下。hosts 窗口与备份视图保持原来的固定高度详情条。
- **分隔项编辑（0.6.0 全宽布局）**：详情面板点「分隔项编辑」或按 `Ctrl+R`，把长值
  按分隔符拆成**占据整个详情区宽度的列表**——双击（或回车）在行上浮出就地编辑框，
  `Esc` 恢复原文，选中行行尾显示 `↑ ↓ ×`（上移 / 下移 / 删除，键盘 `Alt+↑/↓`
  等效），工具条只剩「原文 | 分隔项」切换、分隔符和「+ 新增项」。右侧常驻
  `共 N 项 · 合计 X / 32,767 字符` 计数。每次改动即时拼回该变量的值（仍算一次
  撤销）。`Path` 默认按 `;` 拆分；再按 `Ctrl+R` 回到原文编辑。旧的右侧四按钮
  操作区与竖直分隔条已移除。
- **分隔符**：模式按钮右侧是自绘的下拉按钮（如「分号 (;) ▾」），点开菜单可选
  「分号 / 逗号 / 冒号 / 制表符 / 竖线 / 空格」，选中即生效；选「自定义…」时按钮
  位置换成输入框，可输入任意字符或字符串（例如 `=>`），回车才重切，`Esc` 放弃。
  重切时先把当前各项按旧分隔符拼回完整值，再按新分隔符拆开，值不丢。引号 `"..."`
  内的分隔符不参与拆分。选**空格**总是先确认：PATH 类变量会警告
  `C:\Program Files\...` 会被切成两半（默认否）；其它变量说明连续空白会被归一化，
  含空格的项在列表里带琥珀标记。
- **hosts 条目页**：文件开头的连续注释（如微软自带的说明和 `rhino.acme.com` 示例）
  折叠为一行「文件头注释」，不再被当成停用条目；完整内容在「原文」页查看。同一主机名
  被后面的启用行再次映射时，该行行号旁显示红色 `!`，状态栏给出重复行数。只读时
  不再显示红色横幅，状态栏显示「只读（需管理员）」。
- **hosts 原文页**：整个文件以等宽字体显示，占满窗口。hosts 可写时可以直接编辑；
  离开原文页、按 `Ctrl+S` 或关闭窗口时，改动写回条目，回到条目页按一次 `Ctrl+Z`
  即可撤销整次原文修改。原文框内 `Ctrl+Z / Ctrl+Y` 是文字级撤销 / 重做。换行方式、
  BOM 和文件末尾换行保持不变，没改的行保存后逐字节一致。hosts 只读时原文框也只读。
- **重新载入**：`F5` 从磁盘重读并停留在原来的行；若有未保存的修改会先确认再丢弃。
  外部改动到达时：窗口干净就直接重载，有未保存编辑只提示，不动你的改动。
- **状态栏**：两行。第一行是修改状态、可见行范围、过滤词与读写权限，临时提示
  4 秒后自动消失；第二行是可点击的快捷键条（不可用的操作会灰显）。
- 详情面板内用 `Tab / Shift+Tab` 在字段间前后移动，`Ctrl+Tab / Ctrl+Shift+Tab`
  切换页签。
- `Ctrl+S` 会先列出逐条变更（新增 / 修改 / 删除），确认后才写盘；若其中有删除，
  会单独列出「⚠ 将删除 N 个变量 / hosts 行」及具体名称；含超长值时点名
  「注册表可写入，但新进程可能读不到完整值」。只有**用户**作用域（HKCU）在窗口
  打开后被外部改动才算冲突，此时打开只读差异面板三选一（重新载入 / 强制覆盖 /
  暂不处理），不再有会丢数据的盲覆盖。保存后按当前页签设置重新载入，系统变量行
  不会被抹掉。

## 设置

| 键 | 类型 | 默认值 | 含义 |
|---|---|---|---|
| `hostsPath` | text | `%SystemRoot%\System32\drivers\etc\hosts` | hosts 文件位置 |
| `backupCount` | number | 10 | 每个目标保留的备份数 |
| `maxResults` | number | 50 | 每次查询的最大行数（上限 200） |
